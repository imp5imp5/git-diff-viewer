Сделать из GitDiffViewer локальный инструмент для code review в духе Gerrit: с историей коммитов, постоянно доступной информацией о выбранном коммите и комментариями к строкам, которые можно передать coding agent для исправления.

- [x] Добавить режим **History** для просмотра локальной истории текущего репозитория.
- [x] Показывать историю в отдельной панели со скроллом в раскладке **Wide Diff**.
- [ ] Увеличить стартовую страницу History до 20–30 коммитов. Сейчас загружаются 10 по умолчанию, **Load more** добавляет ещё 10, а `HistoryCommitCount` позволяет изменить стартовое число.

## Режим при запуске

- [ ] Если у текущей ветки есть upstream, по умолчанию открывать **Ready to push**.
- [ ] Если upstream не настроен или репозиторий открыт в detached HEAD, по умолчанию открывать **History**.
- [x] Явно показывать, с каким upstream сравнивается `HEAD`.
- [ ] Не заменять явно сохранённый пользователем режим без понятного правила приоритета.
  Сейчас режим сохраняется, но правило его приоритета после добавления автоматического выбора ещё не определено.
